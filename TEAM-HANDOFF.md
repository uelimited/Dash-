# Dash team project

Dash is Unique Engineers’ project tracker: project overview, TDS, procurement, design, site stock and monthly work planning.

Frontend: Next.js/React in frontend. Backend: Node.js modules in backend, served through Next.js API routes. Database: MySQL. Email sign-in: EmailJS and Better Auth.

The administrator can change records. Invited teammates can view only. ChatGPT collaboration permissions do not grant dashboard admin access.

Keep page components separate. Preserve existing project records and original due dates. Monthly work can record progress, delay explanations and evidence. Delivery-to-stock automation is future work.

Share source through a private repository; a ChatGPT project does not synchronize local folders. Never upload .env files, database dumps, authentication sessions, logs or the original setup conversation.

Local app: http://localhost:3001 (only works on the machine running it). A hosted URL will be supplied after deployment and access verification.
